# prototype

`index.html` is the interactive design reference for rackd, built in gainzy's language
(SF Pro, dark, lowercase, "last time" + PR detection). It's a single self-contained file —
open it in a browser. The real frontend (React/Next or SwiftUI) should match this.

Flow: pick gym (or build a custom workout) → pick the exact machine → log sets → beat your last.
The accent colour is one CSS variable (`--accent`) near the top.
